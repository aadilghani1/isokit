# Code of conduct

isokit follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep criticism about the work, and make room for people who are new. Harassment, insults and personal attacks are not welcome in issues, pull requests, discussions or anywhere else the project lives.

## Reporting

If something happens that breaks this, report it privately to the maintainer, [@aadilghani1](https://github.com/aadilghani1), through a [private security advisory](https://github.com/aadilghani1/isokit/security/advisories/new) or a direct message on GitHub. Reports are kept confidential. The maintainer may remove comments, close threads or block accounts that break the code of conduct, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
