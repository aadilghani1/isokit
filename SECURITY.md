# Security

## Supported versions

The latest minor release of `react-isokit` gets security fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub's private vulnerability reporting](https://github.com/aadilghani1/isokit/security/advisories/new). You will get a reply within a few days, and credit in the release notes if you would like it.

isokit renders static SVG, runs no network requests of its own and stores one value (the sound preference) in `localStorage`.
